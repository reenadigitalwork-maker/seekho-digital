Project submission aur portfolio

1. Project report kaise banayein

Report chhoti aur saaf honi chahiye. Ek project ke liye 1 se 2 page kaafi hain.

  1. Project ka naam aur kis business par kiya (fictional likho).
  2. Maqsad: aap kya hasil karna chahte the.
  3. Aapne kya kiya, step by step.
  4. Output: aapne kya banaya, link ya screenshot ke saath.
  5. Kya galat hua aur kaise sudhaara.
  6. Aapne kya seekha aur agla kadam kya hai.

5. Maine kya seekha
6. Agla kadam

Note: Agar data kalpanik hai to SIMULATED likho.

2. Screenshots aur evidence

Evidence ka matlab hai wo saboot jo dikhaye ki kaam aapne khud kiya. Har screenshot ke saath ek line likho ki usme kya dikh raha hai.

  • Final output ka screenshot (jaise sheet ya doc).
  • Process ka screenshot, jaise keyword list banate waqt.
  • Before aur after screenshot, agar aapne kuch sudhaara.
  • Jahan data kalpanik hai, wahan SIMULATED likha hua dikhna chahiye.

Screenshots mein apna password, phone number, email ya koi private jaankari mat dikhao.

File ka naam aisa rakho: P4-before-title.png. Isse baad mein dhoondhna aasan hota hai.

4. View-only link kaise share karein

  1. Google Drive mein folder ya file ko dabakar rakho aur Share ka option kholo.
  2. General access mein "Anyone with the link" chuno.
  3. Role mein Viewer rakho. Editor mat rakho.
  4. Link copy karo.
  5. Link ko kisi doosre device ya incognito window mein kholo. Agar khul jaye aur edit na ho paye, to sahi hai.

Drive ke menu aur options ke naam badal sakte hain. Agar aapko ye exact naam na dikhein, to Google Drive ki official help dekho.

Jo kuch private ya sensitive hai, use is folder mein mat rakho.

6. Galtiyan aur sudhaar kaise likhein

Galti chhupane se aapka portfolio kamzor lagta hai. Saaf likhne se aapki samajh dikhti hai.

Ek fictional example

Galti: Mere blog ka title bahut lamba tha aur mukhya keyword baad mein aa raha tha.

Sudhaar: Maine title chhota kiya aur keyword shuru mein rakha.

Test: Maine title ek dost ko dikhaya aur poochha ki post ka vishay samajh aaya ya nahi.

Seekh: Title likhne ke baad hamesha ek doosre insaan se padhwana chahiye.

Isi tareeke ko poora seekhne ke liye Improvement page dekho.

7. Portfolio kaise banayein

Portfolio ek jagah hoti hai jahan aapka saara kaam saaf order mein dikhta hai. Shuru mein ek simple index kaafi hai.

  1. Ek Google Doc banao jiska naam Portfolio Index ho.
  2. Upar 3-4 line mein apna parichay likho aur ye ki aap kya seekh rahe ho.
  3. Har project ke liye ek section: project ka naam, ek line ka maqsad, aur report ka view-only link.
  4. Sabse upar capstone case study rakho.
  5. Ek improvement log ka link jodo.
  6. Index doc ko bhi view-only share karo.
